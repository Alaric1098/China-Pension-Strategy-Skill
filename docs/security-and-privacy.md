# 安全与隐私

养老权益记录、身份证件、就业状态和财务信息属于高敏感数据。默认使用本地优先、最小采集、最短保留和显式授权；任何外部模型或服务都不能成为隐含的数据出口。

## 威胁模型

| 威胁 | 入口 | 控制 | 失败响应 |
|---|---|---|---|
| 提示注入 | PDF、OCR文本、网页、文件名、元数据 | 输入按不可信数据隔离；固定系统指令和工具白名单 | 丢弃指令性候选并记录安全事件 |
| 恶意文件 | PDF、DOCX、图片、压缩包 | MIME和魔数校验、大小/页数限制、沙箱解析、禁止宏 | 隔离文件且不进入案件存储 |
| 身份串案 | 文件名、OCR误识别、人工选择错误 | 案件伪名、关键身份字段双确认、来源绑定 | 阻止合并并创建冲突集 |
| 越权访问 | CLI、共享目录、缓存 | 最小权限、每案密钥、目录权限、短期凭据 | 拒绝访问并追加审计事件 |
| 敏感信息泄漏 | 日志、异常、提示、报告元数据 | 结构化脱敏、字段白名单、无原文日志 | 清除派生产物并启动事件响应 |
| 政策来源投毒 | 搜索结果、转载网页、过期缓存 | 权威来源允许列表、摘要固定、双人批准 | 禁止规则包发布 |
| 产物篡改 | JSON、Markdown、DOCX/PDF | 内容摘要、原子发布、运行清单 | 标记摘要不匹配并重新生成 |
| 重放或混淆运行 | 重复请求、旧规则包、缓存碰撞 | 幂等键、双时态、内容寻址 | 返回已有运行或拒绝不兼容版本 |

## 不可信输入和提示注入

所有用户文件、OCR文本、网页内容、政策原文和工具返回值均视为不可信数据。即使内容声称“忽略系统规则”“上传全部文件”或“调用某工具”，也只能作为被分析的字符串，不能成为控制指令。

- LLM看不到文件系统路径、密钥、发布工具或任意网络工具；
- 工具调用由应用层固定工作流批准，不由文档文本动态选择；
- 模型输出先进入候选schema，拒绝未知字段、工具名和外部URL；
- 原始文本使用数据边界和来源ID传入，不拼接到系统指令；
- 需要联网的政策采集使用域名允许列表、内容类型限制和响应大小限制；
- 模型建议的数据外发、权限提升、规则覆盖或发布动作一律拒绝；
- 安全回归集包含中文、图片OCR、表格单元、隐藏文本和多轮间接注入样本。

## 数据分级

| 等级 | 示例 | 允许位置 |
|---|---|---|
| `S0-PUBLIC` | 已发布政策、公开费率 | 版本库和政策缓存 |
| `S1-INTERNAL` | 未发布规则解释、测试用例 | 受控项目存储 |
| `S2-CONFIDENTIAL` | 脱敏案件、场景结果 | 加密案件存储 |
| `S3-RESTRICTED` | 身份证号、原始权益单、银行信息 | 临时隔离区或加密原件库 |

版本库、提交消息、测试夹具和一般日志只允许 `S0`/`S1`。测试使用合成数据，禁止复制真实记录。

## 边界动作

隐私决策同时考虑数据等级、处理边界、用途与授权和目标位置。动作只能为：

- `ALLOW`：原值可在该边界内按批准用途处理；
- `REDACT`：跨越边界前以带类型占位符替换禁止值，只保留计算所需派生事实；
- `BLOCK`：停止该步骤，清除未批准临时产物并返回 `PRIVACY_POLICY_VIOLATION`。

| 数据等级 | Raw intake | Normalized facts | Logs | External service | Report |
|---|---|---|---|---|---|
| `S0-PUBLIC` | ALLOW | ALLOW | ALLOW | 目标服务符合策略时ALLOW | ALLOW |
| `S1-INTERNAL` | ALLOW | ALLOW | REDACT为ID和计数 | 未显式批准时BLOCK | REDACT |
| `S2-CONFIDENTIAL` | 仅案件存储内ALLOW | REDACT为最小计算字段 | 原值BLOCK | 默认BLOCK；取得明确授权且服务获批后仅发送REDACT片段 | REDACT |
| `S3-RESTRICTED` | 仅临时隔离区或加密原件库ALLOW | REDACT，仅保留批准的派生事实 | BLOCK | BLOCK | 原值BLOCK，仅不可识别派生事实可ALLOW |

任何目标位置缺少明确授权、无法满足数据最小化或无法验证服务策略时均选择 `BLOCK`。该矩阵是最低要求；下方外部服务规则可以进一步收紧，不能放宽。

## 保留期限

保留期限以用途和用户授权为上限；部署地区法律要求更短期限时采用更短值。

| 数据 | 默认保留期限 | 到期动作 |
|---|---:|---|
| 上传临时文件和OCR中间页 | 任务结束后立即删除，最长24小时 | 安全删除并记录删除证明 |
| 未纳入案件的候选事实 | 7天 | 删除内容，仅保留无敏感统计 |
| S3原始证据 | 30天或用户撤回授权时 | 删除加密对象及其密钥 |
| 脱敏事实快照和结构化结果 | 90天 | 删除或按新授权续期 |
| 生成的DOCX/PDF | 30天 | 删除产物和下载令牌 |
| 脱敏运行清单和审计事件 | 1年 | 聚合后删除逐案标识 |
| 安全事件记录 | 依法定要求，默认2年 | 审核后安全销毁 |

每类数据必须记录 `classification`、`purpose`、`consent_id`、`created_at`、`expires_at` 和 `deletion_status`。保留作业每日执行、可重试并产生不含敏感内容的删除清单。

## 外部服务

向外部模型、OCR或转换服务发送数据前必须获得用途明确的授权，并验证服务地区、训练数据政策、保留政策和传输加密。默认只发送最小脱敏片段；无法验证零训练或保留期限时，执行 `BLOCK`，改用本地适配器或停止该步骤。
